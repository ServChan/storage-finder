## Что делает мод

На большой базе трудно вспомнить, в каком из сотни сундуков лежат алмазы. Storage Finder запоминает содержимое хранилищ, которые вы открываете, и потом показывает, где искать предмет:

- подсвечивает подходящие сундуки, бочки и шалкеры;
- строит к ним пеший маршрут с обходом препятствий;
- учитывает подписи хранилищ — предметы в рамках на сундуке;
- показывает список активных поисков на экране.

Обычная версия мода пассивная: она ничего не открывает за вас и запоминает только то, что вы открыли сами. На сервер её ставить не нужно.

## Установка

1. Установите [Fabric Loader](https://fabricmc.net/use/installer/) `0.19.3` или новее для Minecraft 26.3.
2. Положите в папку `mods` [Fabric API](https://modrinth.com/mod/fabric-api) для 26.3.
3. Положите в `mods` файл `storage-finder-1.2.2.jar` (как собрать — в разделе [Сборка](#сборка-из-исходников)).
4. Необязательно: [Mod Menu](https://modrinth.com/mod/modmenu) для экрана настроек и LTS_Server Economy `1.1.0+` для цен в HUD.

Нужна Java 25.

## Первые шаги

1. Пройдитесь по своему складу и откройте сундуки, в которых храните вещи. Мод запоминает каждый: в чате появится «Хранилище запомнено: N типов предметов».
2. Возьмите в руку предмет, который нужно найти, и нажмите правый `Alt`.
3. Подходящие хранилища в радиусе 8 чанков подсветятся, к ним протянутся маршруты, а внизу справа появится строка поиска.
4. Заберите предмет — поиск снимется сам. Или нажмите правый `Alt` ещё раз с тем же предметом.

С пустой рукой правый `Alt` открывает экран текстового поиска.

## Как мод узнаёт, что где лежит

- **Открытые хранилища.** Сундуки (одинарные и двойные), бочки и шалкеры записываются, когда сервер прислал их содержимое. Меню плагинов с нестандартным числом слотов не записываются.
- **Изменения.** Если вы что-то положили или взяли, при закрытии хранилища запись обновляется.
- **Рамки.** Предмет в рамке на хранилище считается подписью его содержимого.
- **Свежесть.** У каждой записи видно, как давно её обновляли.
- Индекс хранится отдельно для каждого сервера и каждого мира одиночной игры.

## Поиск

### По предмету в руке

Правый `Alt` с предметом в руке запускает поиск этого предмета, повторное нажатие с тем же предметом его снимает. Одновременно можно искать несколько предметов, у каждого свой цвет.

### Текстовый поиск

Правый `Alt` с пустой рукой открывает экран «Поиск предмета в хранилищах».

- Ищите по названию на текущем языке, по ID (`oak_log`) или по тегу (`#logs`).
- Предметы из уже открытых хранилищ показываются первыми, рядом — сколько их у вас («×64 в хранилищах»).
- Клик или `Enter` — начать поиск.
- ПКМ или `Shift+Enter` — **закрепить** поиск: он не снимется сам.
- Активный поиск отмечен галочкой, клик по нему убирает его.
- Зачарованные книги ищутся по зачарованию.
- «Очистить поиск» снимает все поиски, «Статистика» и «Индекс» открывают свои экраны.

### Когда поиск снимается

Настройка «Снимать поиск»:

| Значение | Что происходит |
|---|---|
| когда взял (по умолчанию) | поиск снимается, как только вы забрали предмет из хранилища |
| при открытии | как только открыли хранилище с ним |
| никогда | только вручную |

Закреплённые поиски сами не снимаются.

## Подсветка и маршруты

- Хранилища с предметом подсвечиваются цветом поиска.
- **Маршрут** строится алгоритмом A* по реальным блокам: ступени и плиты, подъём на 1 блок, безопасный спуск до 3 блоков, плавание, проход через двери и калитки. Лава, костры и открытые люки обходятся.
- На один поиск строится до 3 маршрутов к ближайшим хранилищам (можно до 5).
- Поиск пути ограничен бюджетом узлов за тик (по умолчанию 800), поэтому игра не подвисает даже на больших базах.

## HUD

Внизу справа — список активных поисков:

- значок и название предмета, сколько его нашлось и в скольких хранилищах;
- длина пешего маршрута в метрах;
- возраст данных («стар.») и сколько совпадений нашлось по рамкам;
- «расчёт…», если маршрут ещё строится, и «нет пути» с причиной, если дойти нельзя.

Вид настраивается в «Настройки HUD…»: положение, отступы, компактный режим, расстояние, возраст данных, число строк, прозрачность фона. «Разместить мышью…» открывает предпросмотр, где HUD перетаскивается.

## Статистика и индекс

- **Статистика** — что и где хранится, сводно по предметам.
- **Индекс** — список запомненных хранилищ:
  - фильтр «Текущий мир» или «Все миры» и поиск по координатам или миру;
  - «Удалить выбранное» — забыть одно хранилище;
  - «Очистить текущий мир» — забыть все хранилища этого мира (после подтверждения);
  - «Экспорт снимка» — сохранить индекс в JSON.

## Цены из LTS_Server Economy

Если установлен мод LTS_Server Economy `1.1.0` или новее, при зажатом левом `Alt` HUD показывает для искомых предметов минимальную и среднюю цену за штуку и число магазинов на сервере.

## Настройки

Экран открывается через **Mod Menu → Storage Finder → значок настроек**. Изменения применяются кнопкой «Сохранить»; при выходе с несохранёнными изменениями мод спросит, отменить ли их. Кнопка сброса у строки возвращает значение по умолчанию, «По умолчанию» сбрасывает всё.

### Основные

| Настройка | По умолчанию | Что делает |
|---|---|---|
| Мод включён | да | главный выключатель |
| Запоминать хранилища | да | записывать содержимое открытых хранилищ |
| Искать по рамкам | да | предмет в рамке на хранилище — подпись его содержимого |
| Искать по содержимому | да | искать по запомненному содержимому |
| Подсветка ящиков | да | подсвечивать найденные хранилища |
| Строить маршрут | да | прокладывать путь к ним |
| Обходить опасности | да | обходить лаву, костры и открытые люки |
| Уведомления | да | сообщения в чат «Хранилище запомнено» и подобные |
| Шалкер по Shift | да | с Shift подсказка шалкера показывает его ячейки как в инвентаре |
| Снимать поиск | когда взял | см. [Когда поиск снимается](#когда-поиск-снимается) |
| Радиус | 8 чанков (128 блоков) | где искать хранилища |

### Настройки HUD

| Настройка | По умолчанию |
|---|---|
| Положение HUD | снизу справа |
| Отступ по горизонтали / вертикали | 0 / 48 |

## Macro-версия

Сборка кладёт рядом второй файл — `storage-finder-1.2.2-macro.jar`. Это тот же мод плюс **автопросмотр**:

- пока вы идёте мимо, мод по одному открывает видимые сундуки, бочки и шалкеры в зоне досягаемости, читает содержимое без экрана и закрывает меню через несколько тиков;
- камеру он не поворачивает, звук открытия приглушается;
- одно хранилище перечитывается не чаще раза в 5 минут; ловушечные сундуки и эндер-сундук не трогаются;
- во время приседания, нажатия ЛКМ/ПКМ и при открытом меню автопросмотр ждёт;
- `F8` включает и выключает автопросмотр, параметры — в `config/storage_finder_macro.json`.

**Важно:** сервер видит обычные открытия сундуков. На публичных серверах это может считаться макросом и привести к бану. Используйте macro-версию только там, где это разрешено, а в остальных случаях ставьте обычную. Ставьте только один из двух файлов.

## Файлы

| Путь | Что там |
|---|---|
| `config/storage_finder.json` | настройки |
| `config/storage_finder_index.json` | индекс хранилищ, по серверам и мирам |
| `config/storage_finder_macro.json` | настройки автопросмотра (только macro-версия) |

Запись атомарная через временный файл, с резервной копией `.bak`.

## Частые вопросы

**Поиск ничего не находит.** Мод знает только хранилища, которые вы открывали. Откройте сундуки один раз — дальше они будут в поиске.

**Сундук на сервере с плагином не запоминается.** Если плагин показывает меню с нестандартным числом слотов, мод его не записывает, чтобы не перепутать содержимое.

**«Нет пути».** До хранилища нельзя дойти пешком по известным блокам: оно за стеной, на высоте или за лавой. Подсветка при этом остаётся.

**Игра подтормаживает на огромной базе.** Уменьшите «Узлов A* за тик» и «Маршрутов на запрос».

**Данные устарели.** Откройте хранилище ещё раз — запись обновится. Свежесть видна в HUD и в индексе.

## Сборка из исходников

Нужна JDK 25.

```powershell
git clone https://github.com/ServChan/storage-finder.git
cd storage-finder
.\gradlew.bat build
```

На Linux и macOS используйте `./gradlew`. В `build/libs/` появятся `storage-finder-1.2.2.jar` и `storage-finder-1.2.2-macro.jar`.

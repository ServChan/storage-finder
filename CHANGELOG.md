# Changelog

## 1.0.3 — 2026-07-23

- Добавлена необязательная интеграция с LTS_Server Economy: удержание левого Alt раскрывает в HUD минимальную и среднюю цену за единицу товара по всему текущему серверу.
- Мост цен версионирован и не создаёт жёсткой зависимости: Storage Finder полноценно работает без Economy и показывает понятное состояние при несовместимой старой версии.

- До трёх ближайших достижимых хранилищ теперь находятся одним общим проходом A* вместо полного перезапуска поиска для каждой цели.
- Первый готовый маршрут появляется сразу, пока поиск второй и третьей целей продолжается в фоне.
- Кэшируются рассчитанные поверхности и проверка полного AABB игрока; устаревшие записи очереди больше не расходуют лимит посещённых узлов.
- Эвристика остаётся активной при большом числе конечных клеток и группирует их по хранилищам.
- Конечные клетки ограничены действительно соседними позициями, что резко сокращает число синхронных проверок коллизий и лучей перед запуском A*.
- Линии маршрута заранее рассчитываются и объединяют прямые участки, не запрашивая collision shape для каждой точки на каждом кадре.
- Общий бюджет 800 узлов теперь строго распределяется между всеми активными запросами.
- Переход игрока в соседний блок сразу перебазирует подходящие хвосты маршрутов и отменяет устаревший расчёт, не ожидая полусекундного общего refresh.
- A* строит диагональные переходы с корректной octile-эвристикой и стоимостью `√2`.
- Полный AABB игрока проверяется вдоль всей диагонали, поэтому маршрут не срезает углы сквозь стены, заборы и слишком узкие просветы.
- Разрешён обычный прыжок на один полный блок; реальные collision shape учитывают ковры, плиты, ступени, слои снега и проходимый декор.
- Поддерживаются простые вертикальные участки по лестницам, лианам и строительным лесам.
- Исправлен старт и перебазирование пути на ступенях: кэш и A* используют одну нормализованную клетку поверхности вместо сырого `player.blockPosition()`.
- Высота сложной collision shape измеряется по всей площади ног игрока, а не только в центре блока; верхняя и нижняя половины ступени больше не делают старт невалидным.
- Диагональ теперь требует проходимой опоры в обеих соседних ортогональных клетках и не может срезать внутренний угол лестницы над проёмом.
- Одновременное изменение X/Z и Y отображается настоящей наклонной линией; рендер больше не превращает такой шаг в искусственную связку «вертикаль — горизонталь — вертикаль».

## 1.0.2 — 2026-07-22

- Один JAR теперь поддерживает Minecraft 26.1.2 и 26.2.
- Добавлены совместимые мосты для активного экрана, HUD и Toast Manager.
- Сборка проверяется с соответствующими каждой версии модулями Fabric API.

## 1.0.1 — 2026-07-19

- Индексация воронок, печей, раздатчиков, выбрасывателей, варочных стоек и других контейнерных блоков.
- Закрепление одного поискового запроса правой кнопкой мыши, чтобы он не удалялся после открытия найденного хранилища.
- Общая статистика известных предметов в проиндексированных хранилищах в радиусе до 128 блоков.
- Сохранение точных количеств предметов с обратной совместимостью существующего индекса.
- Количество найденных предметов в активной HUD-панели.
- Выбор угла HUD и регулируемый вертикальный отступ для защиты от перекрытия чатом.
- Исправлено наложение поясняющего текста на элементы экрана настроек.
- Обновлены русская и английская локализации.

## 1.0.0 — 2026-07-16

- Поиск хранилищ по предметным рамкам и запомненному содержимому.
- Несколько цветных запросов из руки и локализованный текстовый поиск с подсказками.
- Раздельный поиск зачарованных книг по виду зачарования без учёта уровня.
- Подсветка всех совпадений и A*-маршруты максимум к трём ближайшим достижимым целям.
- Строгий радиус до 8 чанков, проверка AABB и реальных поверхностей коллизий.
- Индексация обычных/двойных сундуков, бочек и шалкеров; эндер-сундуки исключены.
- Атомарный JSON, повтор записи после ошибки, резервная копия и восстановление.
- Долговременная recovery-копия с максимальным числом известных записей.
- Stroke-only подсветка для совместимости с Iris без `debug_filled_box`.
- Маршруты к бочкам, утопленным заподлицо в пол, с подходом сверху или с соседней клетки пола.
- Явное ручное удаление запросов: повторный Alt с предметом либо щелчок по активному запросу в текстовом поиске.
- Настраиваемая клавиша поиска в стандартном меню управления; правый Alt используется по умолчанию.
- Исправлено запоминание содержимого поставленных шалкеровых ящиков через `ShulkerBoxMenu`.
- Pending association сбрасывается на любом несовместимом контейнерном экране и не наследуется следующим GUI.
- Напольное правило маршрута применяется только к бочкам с крышкой вверх.
- Неудачные неизменные A*-маршруты получили пятсекундный отрицательный кэш вместо пересчёта каждые полсекунды.
- Экран настроек сообщает об ошибке записи и корректно возвращается в Mod Menu.
- Постоянная HUD-панель снизу слева показывает активные запросы, иконки, цвета, совпадения и состояние маршрутов.
- Для книг в HUD отображаются конкретные зачарования, включая книгу с несколькими чарами.
- A* переведён на пошаговую state machine с общим бюджетом 800 узлов на тик вместо блокирующего расчёта до 40 000 узлов за кадр.
- Области данных по серверу, dimension и seed; консервативная legacy-миграция.
- Настройки через Mod Menu, русская и английская локализации.

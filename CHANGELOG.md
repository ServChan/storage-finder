# Changelog

## 1.2.0 — 2026-09-28

- Мод перенесён на Minecraft 26.3; 26.1.2 и 26.2 больше не поддерживаются.
- Ported to Minecraft 26.3; 26.1.2 and 26.2 are no longer supported.

## Unreleased

### Исправления

- Запись индекса больше не выполняется в игровом тике: неизменяемый снимок сохраняется в фоновом потоке, а при закрытии клиента запись дожидается завершения. Ошибка записи показывается один раз до успешного повтора.
- Меню теперь индексируется только после синхронизации содержимого сервером, поэтому первое чтение пустого меню больше не даёт ложное «0 типов».
- Одиночный сундук и бочка принимают только меню на 27 слотов, двойной сундук только на 54: GUI плагина, открытый вскоре после неудачного клика по сундуку, больше не записывается как его содержимое.
- Поиск завершается при открытии хранилища, только если предмет действительно внутри, а не по устаревшей подсветке или рамке.
- Исправлено совпадение цветов после девяти и более поисков: два запроса могли получить один цвет и удаляться вместе.
- Счётчик завершённых поисков считает запросы, а не ключи зачарований.
- Строка HUD больше не накладывает длинный статус на название предмета.
- Подпись в заголовке экранов больше не пересекает разделительную линию.
- Эмодзи-булавка, которую шрифт Minecraft показывает квадратом, заменена текстовой меткой.
- Названия углов HUD не ломаются при турецкой локали системы.
- Проверка README в сборке не зависит от регистра бейджа версии.

### Поиск пути

- Деревянные двери и калитки считаются проходимыми (настраивается); закрытая дверь добавляет небольшую стоимость.
- Разрешён безопасный спуск до трёх блоков с проверкой свободного столба падения.
- Эвристика A* учитывает высоту и остаётся допустимой и согласованной; при равной оценке раскрывается узел ближе к цели.
- Бюджет тика используется полностью: после найденной цели поиск продолжается в том же тике.
- Идущий расчёт не перезапускается при каждом шаге игрока в пределах 4 блоков, а порядок кандидатов больше не сбрасывает задание.
- Игрок, отошедший от линии на один блок, снова привязывается к маршруту без пересчёта.
- Периодический пересчёт больше не мигает: старые маршруты видны, пока новые не готовы.
- В прыжке или полёте маршруты не исчезают; старт ищется до 4 блоков ниже.
- Если рядом с хранилищем нельзя встать, проверяется второе кольцо клеток в пределах досягаемости.
- В A* передаются только ближайшие кандидаты, что убирает всплески нагрузки при сотнях совпадений.
- HUD показывает длину пешего маршрута, а не расстояние по прямой.

### Интерфейс

- Поиск: прокрутка, подсветка под курсором, поиск по ID, количество уже сохранённых предметов, пустой запрос показывает то, что у вас есть.
- Статистика: клик по предмету включает его поиск, активный режим и границы страниц видны.
- Менеджер индекса: номер страницы, прокрутка колесом, поиск координат с запятыми, асинхронный экспорт, выделенное подтверждение очистки.
- Настройки: подсказки ко всем переключателям, сброс значения кликом по центру, индикатор и подтверждение несохранённых изменений, без дублирования настроек HUD.
- Размещение HUD: настоящий предпросмотр, перемещение по всему экрану, стрелки для точной подстройки, кнопка сброса.

## 1.1.0 — 2026-08-11

- Добавлен менеджер локального индекса: фильтрация текущей/всех областей, поиск, возраст и состояние записи, точечное удаление, подтверждаемая очистка текущей области и безопасный JSON-экспорт.
- HUD показывает расстояние, свежесть источника и конкретную причину отсутствия маршрута; добавлены компактный режим, прозрачность, число строк и визуальное размещение перетаскиванием.
- Число маршрутов на запрос настраивается от 1 до 5, общий бюджет A* — от 200 до 2000 узлов за тик.
- Маршруты поддерживают горизонтальное и вертикальное плавание, узкие водные проходы по реальному AABB позы плавания, выход на сушу, плиты, ступени и прочие реальные collision shape.
- Добавлена классификация локальных снимков: свежие, стареющие, устаревшие и данные только из предметной рамки.
- Изменение маршрутных настроек немедленно сбрасывает устаревшие пути и кэши.

## 1.0.6 — 2026-08-11

- Основной мод обновлён до 1.0.6.
- Удалён экспериментальный автосканер: Storage Finder остаётся пассивным клиентским инструментом и индексирует только контейнеры, которые игрок открыл самостоятельно.
- Привязка открытого меню теперь допускает только поддерживаемые типы хранилищ и имеет короткое окно ожидания.
- При смене мира немедленно очищаются найденные блоки, маршруты и незавершённые задания поиска пути.
- Запись индекса объединяет частые изменения, использует паузу после ошибок и ограничивает максимальный размер.
- Повторные выборки записей текущего мира используют кэш, а кандидаты маршрутов собираются без линейного поиска дублей.
- Добавлены модульные тесты политики хранения, проверки метаданных и локализаций, CI для 26.1.2/26.2 и лицензии внутри JAR.

## 1.0.3 — 2026-07-23

- Добавлена необязательная интеграция с LTS_Server Economy: удержание левого Alt раскрывает в HUD минимальную и среднюю цену за единицу товара по всему текущему серверу.
- Мост цен версионирован и не создаёт жёсткой зависимости: Storage Finder полноценно работает без Economy и показывает понятное состояние при несовместимой старой версии.

- До трёх ближайших достижимых хранилищ теперь находятся одним общим проходом A* вместо полного перезапуска поиска для каждой цели.
- Первый готовый маршрут появляется сразу, пока поиск второй и третьей целей продолжается в фоне.
- Кэшируются рассчитанные поверхности и проверка полного AABB игрока; устаревшие записи очереди больше не расходуют лимит посещённых узлов.
- Эвристика остаётся активной при большом числе конечных клеток и группирует их по хранилищам.
- Конечные клетки ограничены действительно соседними позициями, что резко сокращает число синхронных проверок коллизий и лучей перед запуском A*.
- Линии маршрута заранее рассчитываются и объединяют прямые участки, не запрашивая collision shape для каждой точки на каждом кадре.
- Общий бюджет 800 узлов теперь строго распределяется между всеми активными запросами.
- Переход игрока в соседний блок сразу перебазирует подходящие хвосты маршрутов и отменяет устаревший расчёт, не ожидая полусекундного общего refresh.
- A* строит диагональные переходы с корректной octile-эвристикой и стоимостью `√2`.
- Полный AABB игрока проверяется вдоль всей диагонали, поэтому маршрут не срезает углы сквозь стены, заборы и слишком узкие просветы.
- Разрешён обычный прыжок на один полный блок; реальные collision shape учитывают ковры, плиты, ступени, слои снега и проходимый декор.
- Поддерживаются простые вертикальные участки по лестницам, лианам и строительным лесам.
- Исправлен старт и перебазирование пути на ступенях: кэш и A* используют одну нормализованную клетку поверхности вместо сырого `player.blockPosition()`.
- Высота сложной collision shape измеряется по всей площади ног игрока, а не только в центре блока; верхняя и нижняя половины ступени больше не делают старт невалидным.
- Диагональ теперь требует проходимой опоры в обеих соседних ортогональных клетках и не может срезать внутренний угол лестницы над проёмом.
- Одновременное изменение X/Z и Y отображается настоящей наклонной линией; рендер больше не превращает такой шаг в искусственную связку «вертикаль — горизонталь — вертикаль».

## 1.0.0 — 2026-07-16

- Поиск хранилищ по предметным рамкам и запомненному содержимому.
- Несколько цветных запросов из руки и локализованный текстовый поиск с подсказками.
- Раздельный поиск зачарованных книг по виду зачарования без учёта уровня.
- Подсветка всех совпадений и A*-маршруты максимум к трём ближайшим достижимым целям.
- Строгий радиус до 8 чанков, проверка AABB и реальных поверхностей коллизий.
- Индексация обычных/двойных сундуков, бочек и шалкеров; эндер-сундуки исключены.
- Атомарный JSON, повтор записи после ошибки, резервная копия и восстановление.
- Долговременная recovery-копия с максимальным числом известных записей.
- Stroke-only подсветка для совместимости с Iris без `debug_filled_box`.
- Маршруты к бочкам, утопленным заподлицо в пол, с подходом сверху или с соседней клетки пола.
- Явное ручное удаление запросов: повторный Alt с предметом либо щелчок по активному запросу в текстовом поиске.
- Настраиваемая клавиша поиска в стандартном меню управления; правый Alt используется по умолчанию.
- Исправлено запоминание содержимого поставленных шалкеровых ящиков через `ShulkerBoxMenu`.
- Pending association сбрасывается на любом несовместимом контейнерном экране и не наследуется следующим GUI.
- Напольное правило маршрута применяется только к бочкам с крышкой вверх.
- Неудачные неизменные A*-маршруты получили пятсекундный отрицательный кэш вместо пересчёта каждые полсекунды.
- Экран настроек сообщает об ошибке записи и корректно возвращается в Mod Menu.
- Постоянная HUD-панель снизу слева показывает активные запросы, иконки, цвета, совпадения и состояние маршрутов.
- Для книг в HUD отображаются конкретные зачарования, включая книгу с несколькими чарами.
- A* переведён на пошаговую state machine с общим бюджетом 800 узлов на тик вместо блокирующего расчёта до 40 000 узлов за кадр.
- Области данных по серверу, dimension и seed; консервативная legacy-миграция.
- Настройки через Mod Menu, русская и английская локализации.

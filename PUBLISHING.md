Storage Finder — клиентский Fabric-мод для Minecraft 26.1.2. Он запоминает содержимое открытых сундуков, бочек и шалкеровых ящиков, использует предметные рамки как дополнительный источник, подсвечивает найденные хранилища и строит безопасные наземные маршруты. Серверная установка не требуется.

### Полное описание

## Найдите нужный предмет — Storage Finder покажет, где он лежит

Storage Finder — полностью клиентский Fabric-мод для Minecraft 26.1.2. Он создаёт локальный индекс хранилищ, которые вы уже открывали, объединяет эти данные с видимыми предметными рамками, подсвечивает все совпадения и строит безопасные наземные маршруты максимум к трём ближайшим достижимым целям.

### Основные возможности

- Поиск в сундуках, сундуках-ловушках, бочках и поставленных шалкеровых ящиках.
- Поиск по предмету в руке или локализованному названию через удобный каталог.
- Несколько одновременных запросов с разными цветами.
- Цветная подсветка всех подходящих хранилищ.
- Компактная HUD-панель с иконками, количеством совпадений и состоянием маршрутов.
- Безопасные наземные маршруты на основе пошагового multi-goal A*.
- Учёт стен, полного хитбокса игрока, плит, ступеней, ковров, снега, перепадов высоты и опасных поверхностей.
- Строгий настраиваемый радиус до восьми чанков, или 128 блоков.
- Полностью локальное хранение данных с резервными копиями и разделением серверов, миров и измерений.
- Совместимость с Sodium, Iris и Voxy: мод не заменяет рендер чанков и не загружает чанки принудительно.

### Как пользоваться

Возьмите нужный предмет в основную руку и нажмите клавишу поиска — по умолчанию это правый Alt. Повторное нажатие отключит запрос. Чтобы искать по названию, освободите основную руку и нажмите ту же клавишу: откроется каталог, использующий текущий язык Minecraft.

Открывайте контейнеры как обычно, чтобы Storage Finder запоминал их содержимое. Инвентарь игрока не индексируется. После открытия подходящего хранилища автоматически отключаются только те запросы, которые были найдены именно в нём.

### Как сравниваются предметы

Обычные предметы сравниваются по базовому типу. Название, прочность и обычные зачарования не влияют на совпадение. Зачарованные книги обрабатываются отдельно по каждому виду записанных чар, но без учёта уровня и пользовательского имени.

### Важные ограничения

Клиент не может прочитать содержимое закрытого контейнера, который вы ещё не открывали. Поиск работает только в уже загруженных клиентом чанках и не заставляет игру загружать новые. Маршруты предназначены для обычного передвижения по земле: они не планируют открывание дверей, плавание, полёт, лестницы или сложный паркур.

### Требования

- Minecraft 26.1.2
- Fabric Loader 0.19.3 или совместимая версия
- Java 25
- Fabric API
- Mod Menu — необязательно, используется для графического экрана настроек

Storage Finder устанавливается только на клиент. Серверная версия не требуется.
